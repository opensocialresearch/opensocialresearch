# Open Social Research

Herramienta libre para hacer investigación social aplicada de punta a punta:
desde el diseño del proyecto y el trabajo de campo hasta el análisis, la
escritura y la divulgación. Quiere ser una alternativa abierta a Atlas.ti que
no se case con ningún enfoque.

Nace para el programa de Investigación Social Aplicada (ISA) de la UNED, donde
la usa primero Carlos Aguero. Después se abre a colegas.

## Idea guía

Pluralismo metodológico: no existe una única «vía óptima» para investigar
(Della Porta y Keating, 2013, *Enfoques y metodologías de las ciencias
sociales. Una perspectiva pluralista*). La herramienta sirve igual para
investigación cuantitativa, cualitativa o mixta, y para distintas
epistemologías.

## Lo que se quiere que haga

- **Proyecto y escritura**: redactar el proyecto, llevar bitácoras, citar con
  Zotero, generar el PDF final y el sitio web de divulgación.
- **Campo**: aplicación móvil para recolectar en terreno (notas, audio, fotos,
  ubicación).
- **Análisis cualitativo**: transcripción de entrevistas, codificación,
  análisis de textos.
- **Análisis cuantitativo**: estadística y visualización de datos.
- **Análisis geográfico**: mapas y análisis espacial.
- **Inteligencia artificial**: asistencia en transcripción, clasificación y
  análisis, siempre bajo el criterio de quien investiga.
- **Plataformas**: web para el trabajo de escritorio y móvil para el campo.
